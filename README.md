# Bassma Alaoui Sossey — Official Portfolio Website

Official academic and engineering portfolio website of **Bassma Alaoui Sossey**, Final-Year Cybersecurity Engineering Student at Université Euromed de Fès (UEMF).

🌐 **Live Website:** [https://bassma202.github.io/](https://bassma202.github.io/)

---

## 📌 Architecture & Contents
Built with semantic HTML5, modern CSS3 (glassmorphic dark cyber theme), and vanilla JavaScript. Zero heavy frameworks, 100% lightweight and responsive.

### Sections (Following MAIR Academic Portfolio Framework):
1. **Hero & Status:** PFE 2027 availability status, quantified metrics bar.
2. **About Me:** Education at UEMF, DataPathology internship, core engineering philosophy.
3. **Research & Technical Focus:** 6 core cybersecurity pillars (GRC & FAIR, Zero-Trust IAM, DevSecOps, DFIR & Detection-as-Code, Defensive AI, OT/SCADA).
4. **Flagship Projects:** Interactive showcase of all 6 GitHub repositories with real-time category filtering.
5. **Technical Reports & Publications:** Downloadable interview dossier, risk methodology whitepaper, and industrial architecture specifications.
6. **Contact & Downloads:** Direct contact information, copy-to-clipboard email, and one-click downloads for her 1-page vector CV in English and French.

## 🚀 Local Development
Simply open `index.html` in any modern web browser or serve with:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
