# Bassma Alaoui Sossey — Official Portfolio Website

Official cybersecurity engineering portfolio website of **Bassma Alaoui Sossey**, Final-Year Cybersecurity Engineering Student at Université Euromed de Fès (UEMF).

🌐 **Live Website:** [https://bassma202.github.io/](https://bassma202.github.io/)

## 📌 Architecture & Design
Clean, modern light-theme portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript. Fast, lightweight, and fully responsive.

### Sections:
1. **Hero & Status:** PFE 2027 availability status, quantified metrics bar.
2. **About Me:** Education at UEMF, DataPathology internship, core engineering philosophy.
3. **Core Engineering Domains:** 6 operational cybersecurity pillars (GRC & FAIR, Zero-Trust IAM, DevSecOps, DFIR & Detection-as-Code, Defensive AI, OT/SCADA).
4. **Flagship Projects:** Interactive showcase of all 6 GitHub repositories with real-time category filtering.
5. **Technical Documentation & Guides:** Downloadable interview dossier, risk methodology whitepaper, and industrial architecture specifications.
6. **Contact & Downloads:** Direct contact information, copy-to-clipboard email, and one-click downloads for her 1-page vector CV in English and French.
